# Wordle
[[English](./README.md)|**中文**]

### 如何玩 Wordle？

**以下是 Wordle 的基本规则：**

- 你必须在 6 次尝试内猜出隐藏的单词，字母的颜色会变化以显示你猜测的接近程度。
- 要开始游戏，只需输入任意一个存在的英文单词，然后你将获得反馈：
  - **绿色** - 绿色字母表示该字母在单词中且位置正确；
  - **黄色** - 黄色字母表示该字母在单词中但位置错误；
  - **灰色** - 灰色字母表示该字母完全不在目标单词中。
- 如果你在 6 次尝试内成功猜出答案，你将获胜，否则将失败。

**有 2 种方式可以开始游戏：**
1. **在线游玩** - 访问 [Wordle (god-forever.github.io/wordle)](https://god-forever.github.io/wordle/) 进行游戏；
2. **下载资源** - 下载此仓库，然后通过打开 `index.html` 即可开始游戏。

### 关于我们的 Wordle 游戏！

我们的游戏具有简洁美观的界面、便捷的操作和丰富的扩展玩法。**以下是我们的游戏介绍：**

- **词库**

  使用包含 917,270 个（有效）单词的词库来判断用户输入是否为单词。

  标准模式下的答案将从包含 86,876 个（有效）单词的词库中选择。

- **方块**

  你输入的单词将显示在方块中。当你按下 `Enter` 键后，当前行的方块将着色以反映每个字母的准确性。

- **键盘**

  我们在网页界面上提供了虚拟键盘。同时，你也可以使用物理键盘输入单词。

  提交单词后，虚拟键盘也会着色，以便你获得关于某个字母的提示。

- **按钮**

  主界面上有 5 个按钮，分别是：

  - **显示答案 (Answer)** - 显示当前回合游戏的答案，如果游戏尚未结束，你将自动失败；
  - **重玩 (Replay)** - 重新开始游戏并重置答案；
  - **设置 (Setting)** - 设置单词长度，更改游戏模式，并生成自定义单词的游戏。
  - **粘贴 (Paste)** - 与 `Ctrl+V` 功能相同，用于粘贴分享链接。
  - **Github** - 跳转到 [Github 仓库](https://github.com/God-Forever/wordle)。

- **答案**

  点击答案或在主界面上使用快捷键 `Ctrl+A` 可打开答案菜单。答案菜单包含两部分，一部分显示目标单词是什么，另一部分显示其中文含义。

  菜单底部有 2 个按钮，一个允许你通过复制方块颜色来分享你的记录（也包括分享链接。快捷键：`Ctrl+S`），另一个允许你重新开始游戏（快捷键：`Ctrl+R`。在主界面上按 `Ctrl+R` 也可以重新开始）。

- **设置**

  顶部的 **字母数量 (Number of Letters)** 允许你通过点击相应的数字来更改单词长度（从 4 到 11）。按相应的数字键也可以实现此效果（键 `A` 对应 10，键 `B` 对应 11）。

  底部的 **自定义单词 (Custom Word)** 允许你使用自定义答案生成自定义游戏链接。你只需输入一个单词并点击 **复制链接 (Copy Link)**（快捷键：`Enter`，仅在输入框获得焦点时有效），然后你就可以将链接分享给朋友挑战他们。你也可以直接在朋友面前输入单词，这需要你更改输入文本的可见性（快捷键：`Ctrl+S`，仅在输入框获得焦点时有效）。你可以按 `Tab` 键来聚焦或取消聚焦输入框。

  其他选项是各种游戏模式，你也可以使用快捷键 `ctrl+<模式名称的首字母>` 来开启或关闭。以下是它们的介绍：

  - **熟悉模式 (Familiar Mode)** - 答案将从"前 10,000 个单词"的较小词库中选择，实际上包含 6,053 个（有效）单词。此模式将使游戏更容易；
  - **循环模式 (Circle Mode)** - 在此模式下，每个游戏的第一次尝试将用相同长度的上一个游戏的答案填充；
  - **严格模式 (Strict Mode)** - 这是原始 Wordle 中困难模式的升级版。要求玩家输入符合所有已知信息的单词。对于不符合要求的单词，将不会被接受，并向玩家提供关于第一个不匹配信息的反馈；
  - **困难模式 (Hard Mode)** - 在标准游戏中，每种颜色都会显示在相应位置。然而，在此模式下，颜色不会显示在它们的位置上，而是在每行末尾给出每种颜色的数量。

  不同寻常的是，由于困难模式中信息呈现方式的不同，当严格模式开启时，困难模式会有特殊的反馈。

  当困难模式开启时，单词长度将限制为 4 到 8；

  - **无限模式 (Infinity Mode)** - 你可以有无限次的尝试而不会失败。如果你开启的其他模式可能在六次尝试内太难成功，你可以开启此模式。

- **加载分享链接**

  直接点击 **分享 (Share)** 或 **复制链接 (Copy Link)** 获得的链接将开始一个游戏，其答案取决于该链接。你也可以按 `Ctrl+V` 或点击 **粘贴 (Paste)** 来加载分享链接，而无需重新加载页面。

- **标注**

  你可以通过右键单击（或在移动设备上长按）虚拟键盘上的字母，或按 `Shift+<相应键>` 来用颜色进行标注。如果 **困难模式** 开启，你也可以在已提交的方块上进行标注。

- **PWA (渐进式网页应用)**

  我们游戏的在线版本支持 PWA，这意味着你可以将网页作为应用程序安装到你的设备上。

- **词库编辑工具**

  离线版本提供了一个 Python 脚本 `word_manager.py`，它允许你在本地设备上编辑词库。有关使用详情，请参考程序运行时自动打印的简短文档。
